# Day 4 - Notes UI

A simple React Notes application built using React and Vite.

## Features

- Add a note using the input box and Add button
- Display notes as a list
- Delete individual notes
- Prevent empty notes from being added
- Notes are managed using React useState
- Notes are stored as an array of note objects

## Technologies Used

- React
- Vite
- JavaScript
- CSS
